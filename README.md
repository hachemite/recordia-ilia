# RecordiaILIA

**RecordiaILIA** is a lightweight desktop utility designed for quick screenshot capture and screen recording, tailored with custom hotkeys and seamless local file saving. 

## Team
- **Hachem**: Architecture, Core Capture/Recording Logic
- **Yassine Ouali**: User Interface, Settings, and File Management

## Features
- 🖥️ **Interactive UI**: Clean, intuitive interface for managing captures.
- ⚡ **Hotkeys**: Global shortcuts for instant triggering.
- 📸 **Screenshot Capture**: Snip and save full screen or custom regions.
- 🎥 **Screen Recording**: Record video output smoothly with configurable settings.
- ⚙️ **Settings & Storage**: Automatic local organization of recordings and screenshots.

## Tech Stack
- Python (Desktop App Framework & Core Logic)
